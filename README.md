# Goulash Реклама

Кабинет для подготовки поисковой кампании в Яндекс Директе. Владелец описывает бизнес, проверяет объявление и лимит, создаёт выключенный черновик и сверяет результаты. В журнале можно посмотреть причину изменения и отменить поддержанную правку.

## Попробовать на учебных данных

Нужны Git и **Node.js 24.12 или новее в ветке 24**. SQLite входит в Node.js. Команды выполняются из корня клона. В Windows PowerShell вместо `npm` можно использовать `npm.cmd`.

```sh
node --version
npm run training
```

Откройте **адрес учебного входа из терминала**. Стенд сам выберет свободный порт, создаст базу в `output/training` и откроет кабинет учебного владельца. Оставьте терминал открытым. При повторном запуске данные сохранятся. Для остановки нажмите Ctrl+C. Для дополнительного примера со статистикой выполните во втором терминале `npm run training:rollstar` и откройте напечатанный им адрес.

1. [Пройти пять сценариев приёмки](docs/handoff/ACCEPTANCE.md) — действия, ожидаемые результаты и условия сверки на настоящем кабинете.
2. [Установить сервис и настроить интеграции](docs/handoff/SETUP.md) — запуск с Яндекс ID, параметры Директа, Метрики и DeepSeek, сборка, резервирование и восстановление.
3. [Посмотреть состав исходников и лицензии](docs/handoff/COMPONENTS.md) и [каталог компонентов интерфейса](docs/handoff/DESIGN.md).

Полный прогон тестов из этого клона запускается командой `npm test`. Нужны доступ к loopback, Git и tar в PATH. Устанавливать npm-зависимости для приложения и тестов не требуется. Несколько проверок различаются для Windows и Linux.

Учебный контур использует имитации Директа, Метрики и модели. Для живой проверки требуются согласованные доступы. Демонстрация проверяет выключенный черновик, чтение отчётов и работу автоматики на учебных данных. Платные показы и оценка привлечённых клиентов относятся к отдельному пилоту.
